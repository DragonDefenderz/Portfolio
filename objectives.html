Objectives

Objective 1

Demonstrate and communicate aesthetic skills and choices based on traditional art theories and current game development practices and next-generation research.

Visual Storytelling
✦ How it contributes

These projects show how I use composition, lighting, color, and character design to communicate a story or feeling visually. Each piece was designed with a specific mood or idea in mind, allowing the artwork itself to help tell the story.

Traditional Anatomy Studies
✦ How it contributes

These studies helped me build a stronger understanding of anatomy, proportion, form, and how the body moves. Practicing both drawing and sculpture also helped me understand three-dimensional forms that I can apply when creating characters digitally.

Objective 2

Conceptualize and generate pre-production art assets through pre-visualization and prototypes usable for multiple game platforms.

Shot Frame Study
✦ How it contributes

These shot studies show how I planned compositions, camera angles, and character placement before moving into the final animation. Creating these early versions allowed me to test different ideas and make changes before committing to the finished scene.

World Showcase
✦ How it contributes

This project shows how I planned and tested assets before bringing them into the final environment. Working through the models, UVs, textures, and early engine implementation helped me make sure the assets would work together properly before completing the scene.

Objective 3

Demonstrate the core skills needed to create 2D and 3D art assets textures and animations utilizing industry-standard software tools.

Game Ready Character Development
✦ How it contributes

This character demonstrates the core skills I have developed for creating game-ready characters, including sculpting, retopology, UV mapping, texturing, and presentation. It also shows my ability to take a character through multiple stages of the 3D production process.

Hard-Surface Modeling & Visualization
✦ How it contributes

This motorcycle demonstrates my hard-surface modeling skills and my understanding of topology, materials, lighting, and rendering. Taking the asset from the initial model to the final presentation helped me practice the full workflow used to create polished 3D props.

Objective 4

Create industry quality 2D and 3D art assets or animations for use in game projects utilizing industry-standard software tools pipelines and platform guidelines.

Game Development Process Documentation
✦ How it contributes

These videos document my process of creating assets and preparing them for use inside a game engine. They show how I approach modeling, UVs, materials, and implementation while following a workflow that can be used during actual game production.

B.A.R.F. Demo
✦ How it contributes

This project shows my ability to take my work beyond individual assets and contribute to a completed game project. It demonstrates how I applied my art and technical skills within an actual development process while working toward a polished final result.

Objective 5

Adapt export integrate and optimize game art and animation assets including shaders and lighting into 2D and 3D game projects working within a production pipeline and the confines of a project's game engine tools and other constraints.

Engine Integration
✦ How it contributes

These projects show how I bring art assets into Unreal Engine and build systems around them using Blueprints, materials, procedural tools, and other engine features. They demonstrate my ability to work between the artistic and technical sides of development while keeping the assets functional inside a real-time environment.

Production-Ready Asset
✦ How it contributes

This character shows how I prepare an asset for use in a real-time project. The topology, UVs, and textures were created with both appearance and performance in mind, helping me practice the optimization and organization required for game-ready assets.

Objective 6

Establish collaboration mentorship and professional leadership skills by working with other disciplines to deliver highly polished and completed projects.

Team Collaboration
✦ How it contributes

These assets were created as part of a larger team project, so my work had to match the style and technical requirements established by the group. It gave me experience receiving feedback, following a shared direction, and creating assets that needed to work alongside the work of other artists.

Class Team Building
✦ How it contributes

These projects gave me experience working with classmates to create something that would not have been possible individually. I had to communicate with other team members, divide responsibilities, respond to feedback, and make sure my work fit together with what everyone else was creating.
