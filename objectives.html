Objective 1

Demonstrate and communicate aesthetic skills and choices based on traditional art theories and current game development practices and next-generation research.

Visual Storytelling
✦ How it contributes

This collection showcases projects that demonstrate the use of composition, color theory, lighting, and character design to communicate narrative, emotion, and atmosphere. Each piece emphasizes intentional artistic decisions that support storytelling while reflecting modern game art principles and stylized visual development.

Traditional Anatomy Studies
✦ How it contributes

Through observational drawing and traditional sculpture, this collection explores the structure of the human body, including muscular systems, skeletal landmarks, and anatomical proportions. These studies developed a deeper understanding of form, balance, and movement.

Objective 2

Conceptualize and generate pre-production art assets through pre-visualization and prototypes usable for multiple game platforms.

Shot Frame Study
✦ How it contributes

These rough composition studies focus on staging, shot framing, and camera progression to visualize how the scene unfolds over time. Testing different viewpoints and character interactions during pre-production ensured that the narrative remained visually clear and engaging before animation.

Environment Production Showcase
✦ How it contributes

This series highlights the relationship between asset creation and engine implementation. By reviewing UV layouts alongside in-engine prototypes, I established a structured workflow that connected modeling, texturing, and scene assembly into a cohesive pre-production process.

Objective 3

Demonstrate the core skills needed to create 2D and 3D art assets textures and animations utilizing industry-standard software tools.

Game Ready Character Development
✦ How it contributes

This collection showcases the complete development of a stylized game-ready character, from concept interpretation and digital sculpting to topology optimization, UV mapping, texture creation, and final presentation. The project demonstrates foundational skills in character production while applying industry-standard workflows to create an optimized asset suitable for real-time game engines.

Hard-Surface Modeling & Visualization
✦ How it contributes

This project demonstrates the complete creation of a game-ready motorcycle asset, including hard-surface modeling, clean topology, material creation, lighting, and high-quality rendering. The wireframe and final renders showcase an understanding of production-ready asset development and industry-standard 3D workflows.

Objective 4

Create industry quality 2D and 3D art assets or animations for use in game projects utilizing industry-standard software tools pipelines and platform guidelines.

These videos demonstrate professional communication by documenting the development process of game assets from creation through implementation in Unity. They explain modeling workflows, UV layouts, material setup, and engine integration, highlighting the ability to communicate technical information effectively while showcasing production-ready development practices.

B.A.R.F. Demo
✦ How it contributes

This presentation demonstrates my ability to communicate the technical and creative decisions behind a game development project. By explaining the development process, design choices, production workflow, and implementation techniques, I showcase not only the finished results but also the reasoning that guided each stage of development. Presenting complex technical information in a clear and organized manner reflects the collaboration and communication skills expected within professional game development teams.

Objective 5

Adapt export integrate and optimize game art and animation assets including shaders and lighting into 2D and 3D game projects working within a production pipeline and the confines of a project's game engine tools and other constraints.

Engine Integration
✦ How it contributes

This collection demonstrates the implementation of technical art workflows within Unreal Engine 5, including procedural environment generation, custom Blueprint scripting, material development, and real-time engine integration. These projects highlight my ability to bridge art and technology by creating efficient tools and workflows that improve production while maintaining visual quality and performance.

Production-Ready Asset
✦ How it contributes

This project demonstrates the technical preparation of a stylized character for real-time applications through optimized topology, efficient UV layouts, and organized texture creation. Objective 6

Establish collaboration mentorship and professional leadership skills by working with other disciplines to deliver highly polished and completed projects.

Team Collaboration
✦ How it contributes

My responsibilities included creating production-ready hard-surface assets while maintaining consistency with the project's artistic direction, technical requirements, and established production pipeline. Through collaboration, iterative feedback, and adherence to team standards, these assets contributed to a cohesive environment designed for real-time implementation.

Class Team Building

These projects demonstrate my experience working within collaborative game art production pipelines, where successful outcomes depended on communication, organization, and coordinated asset development.
